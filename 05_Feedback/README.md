## Where to comment

- For an existing topic, open the related Issue and add a comment at the bottom.
- For a new topic, create a new Issue.
- For a clear documentation correction, identify the document and section.
- For a design proposal, describe the problem, expected behavior, risks, and suggested alternative.
- Never post credentials, personal information, private Drive links, production data, raw financial data, real symbols, prices, holdings, recipients, private prompts, or core decision algorithms.

Straightforward factual questions may receive an AI-assisted reply. Material architecture decisions and rule changes require human review and approval. See the repository [Disclaimer](../DISCLAIMER.md).
